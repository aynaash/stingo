# Concurrency in Go, in five minutes

A 4:50 vertical explainer — 52 scenes, every cut on a bar line.

```bash
bun stingo plan   examples/goroutines/video.yaml    # inspect the timeline
bun stingo render examples/goroutines/video.yaml    # 1080x1920
bun stingo render examples/goroutines/video.yaml --horizontal --taste bootdev
bun stingo preview examples/goroutines/video.yaml   # scrub it
```

`video.yaml` is the script. `taste.json` is the look — swap it for `bootdev` or
`dusk` and the same 52 scenes come out as a different film.
